Dữ liệu và sao lưu

Đang kiểm tra nơi lưu dữ liệu…

Dữ liệu khách nằm trên thiết bị này. Nếu đã có bộ đề, hãy xuất file sao lưu rồi nạp lại sau khi đăng nhập.

Kết nối một repo GitHub riêng tư để dùng chung bộ đề và tiến trình giữa điện thoại và máy tính. Mỗi thiết bị chỉ cần kết nối một lần. Token chỉ lưu trên thiết bị này.

Chưa có token? Làm 3 bước:

  1. Bấm nút dưới đây. GitHub mở form đã điền sẵn tên, thời hạn 1 năm và quyền Contents: Read and write.
  2. Ở Repository access, chọn Only select repositories rồi chọn repo dữ liệu (ví dụ quizscanner-data).
  3. Kéo xuống cuối, bấm Generate token, sao chép token rồi dán vào ô Token GitHub ở trên. Điện thoại và máy tính dùng chung một token được.

Cài đặt API AI

Chọn nhà cung cấp, đăng nhập (OpenRouter) hoặc nhập API key rồi chọn model. Có thể kết nối nhiều nhà cung cấp: model nào không dùng được thì web tự đổi model, cả tài khoản đều không dùng được thì chuyển sang tài khoản tiếp theo.

Trình duyệt lưu key trên thiết bị này và gửi trực tiếp đến nhà cung cấp. OpenAI và Claude không cho đăng nhập từ web khác nên cần API key.

    API cần hỗ trợ OpenAI Chat Completions và cho phép gọi từ trình duyệt (CORS).

    Đăng nhập để dùng credit của tài khoản OpenRouter (có cả model miễn phí). Hoặc dán API key bên dưới.
